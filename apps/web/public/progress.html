Key Data Flows

📦 Order Lifecycle

CREATED → PAID → SEARCHING → RIDER ASSIGNED → PICKED UP → IN TRANSIT → DELIVERED | ARRIVED AT STATION → READY → COLLECTED
Live All statuses implemented via OrderEvent audit trail

🎯 Dispatch Engine Flow

Consumer → POST /dispatch/:orderId/start
↓
Haversine: find ONLINE riders within radius
↓
Create Dispatch + DispatchAttempts
Rider → GET /attempts/pending
Rider → POST /attempts/:id/accept → auto-declines others
Rider → POST /attempts/:id/decline
Live Planned BullMQ timeout handling

🏪 Pickup Station Parcel Flow

Rider → POST /stations/:id/parcels/receive
Station Operator → PATCH /parcels/:parcelId/ready ARRIVED → READY_FOR_COLLECTION
Consumer → POST /orders/:orderId/pickup-code 6-digit code (SHA-256) + QR token
Recipient → POST /parcels/:parcelId/collect Code verified → COLLECTED
Live WIP STORED status, return flow

💳 Payment Flow

Consumer → POST /payments/initialize/order
↓
Paystack Checkout → POST /payments/webhook HMAC-SHA512 verified
↓
Order → PAID · Payment → SUCCESS
Consumer → POST /payments/orders/:orderId/pay Wallet debit (atomic)
Live Two payment methods: Paystack + Wallet
