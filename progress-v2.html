Key Data Flows

📦 Order Lifecycle

CREATED → PAID → SEARCHING → RIDER ASSIGNED → PICKED UP → IN TRANSIT → DELIVERED | ARRIVED AT STATION → READY → STORED → COLLECTED | RETURNED
Live All statuses via OrderEvent audit trail · Live 24h unpaid expiry job (BullMQ)

💰 Monnify Funding & Ledger Flow

Merchant → Monnify VA → Bank Transfer
↓
Monnify Webhook → POST /payments/monnify/webhook HMAC-SHA512 verified
↓
provider_transactions → FUNDING ledger entry idempotent: MONNIFY_<ref>
Consumer → POST /orders/:orderId/pay available → reserved
DELIVERED → settleDelivery 80% rider/company · 20% platform
Live Double-entry ledger in kobo (BigInt)

🎯 Dispatch Engine Flow

Consumer → POST /dispatch/:orderId/start
↓
Redis GEO: ONLINE riders in radius
↓
Dispatch + attempts created
↓
BullMQ 60s timeout job in-process fallback
Rider → POST /attempts/:id/accept → auto-declines others
Return flow → POST /orders/:orderId/return
Live BullMQ timeout + Redis GEO

💳 Withdrawal Flow

Rider / Station → POST /withdrawals
↓
Actor eligibility check INDEPENDENT_RIDER / LOGISTICS / PICKUP only
↓
Monnify Name Enquiry mismatch aborts
↓
Ledger hold: available → reserved
↓
Monnify Disbursement w/ idempotency key
Webhook → consume / reverse hold
Live State machine: REQUESTED → PROCESSING → SUCCESSFUL/FAILED/REVERSED
